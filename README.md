# Laravel E-commerce Management System

A web-based e-commerce management system developed using Laravel, MySQL, Bootstrap, JavaScript and jQuery AJAX.

## Features

- Customer Management (CRUD)
- Category Management (CRUD)
- Product Management (CRUD)
- Order Management (CRUD)
- Dashboard with summary statistics
- Payment Management (in progress)
- AJAX-based requests and JSON responses
- **Page reload-free CRUD operations using AJAX for adding, editing, and deleting records**
- Dynamic data updates without refreshing the entire page

## Technologies Used

- PHP
- Laravel
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery AJAX

## Installation

1. Clone this repository.
2. Run `composer install`.
3. Copy `.env.example` to `.env`.
4. Configure your MySQL database in `.env`.
5. Run `php artisan key:generate`.
6. Run `php artisan migrate`.
7. Start the application using `php artisan serve`.
